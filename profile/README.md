# OrbitFabric

**Model-first Mission Data Fabric for space software and operations.**

OrbitFabric is an open-source ecosystem for keeping mission architecture, interfaces, integrations, and engineering evidence aligned across flight and ground software.

## Ecosystem

OrbitFabric is organized around a small set of complementary components:

- **Core** defines and validates the mission model and its derived contracts.
- **Studio** provides an interactive environment to explore, inspect, and validate mission data and evidence.
- **Reference Mission** provides reproducible end-to-end examples and acceptance paths.
- **Adapters** connect OrbitFabric models and evidence to external flight and ground software ecosystems.

Current integration work includes F´, OpenC3 COSMOS, cFS/EDS, and OpenOBSW/OpenSVF.
